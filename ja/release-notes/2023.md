<a id="november-28-2023"></a>
### 2023. 11. 28. { #november-28-2023 }
* [API]カカともへのメッセージワイドイメージボタン数制限を変更
    * (変更前)カカともへのメッセージワイドイメージ送信時の最大ボタン数1個
    * (変更後)カカともへのメッセージワイドイメージ送信時の最大ボタン数2個

<a id="september-26-2023"></a>
### 2023. 09. 26. { #september-26-2023 }
* [コンソール]お知らせトークチャンネル追加時に案内される固定文言を変更
    * (変更前)チャンネルを追加し、このチャンネルの広告とマーケティングメッセージをカカオトークで受信する
    * (変更後)チャンネルを追加し、このチャンネルのマーケティングメッセージなどをカカオトークで受信する
* [コンソール]本人認証の否認理由を表示
    * 本人認証タブでツールチップの形で否認理由を確認できるように改善しました。

<a id="august-29-2023"></a>
### 2023. 08. 29. { #august-29-2023 }
* [API]メッセージ送信結果コードアップデートウェブフックフィールド追加
    * メッセージ送信結果コードアップデートウェブフックにrecipientGroupingKey, senderGroupingKeyフィールドを追加しました。
* [コンソール]送信結果照会総件数表示を改善
    * 送信結果が10万件以上の場合、合計件数が「99,999+件」のように表示されるように改善しました（従来は1万件以上）。

<a id="july-25-2023"></a>
### 2023. 07. 25. { #july-25-2023 }
* [コンソール]ファイルアップロードを利用したテンプレート登録機能に新規フィールドを追加(v2.3)
    * ファイルのアップロードを利用したテンプレート登録時に、通知トークのアイテムリスト、直接接続、代表リンクなどの新規フィールドが適用できるように改善しました。
* [コンソール]本人認証手続きの改善
    * 本人認証の否認および再要求時に、ユーザーが組織に登録された事業者登録証を変更できるように改善しました。
    * 本人認証の際、その他書類の添付項目を追加しました。
