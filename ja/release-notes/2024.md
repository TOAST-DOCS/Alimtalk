### 2024. 06. 25. { #june-25-2024 }
* [API]特定フィールドに取り消し線スタイルを使用できるように改善

    * お知らせトークアイテムリスト型要約フィールド入力後、削除時に初期化されないバグを修正しました。

<a id="march-26-2024"></a>
### 2024. 03. 26. { #march-26-2024 }
* [コンソール]ロールの細分化
    * ロールに基づいてKakaoTalk Bizmessageメニューへのアクセスと機能制御権限が別途付与されるように機能が追加されました。
    * ロールの設定方法は[コンソール使用ガイド > メンバー管理 > プロジェクトメンバー](https://docs.nhncloud.com/ko/nhncloud/ko/console-guide/#_24)の項を参照してください。
* [API] 登録済みのテンプレートをチャンネル追加型テンプレートに切り替えるAPIを追加
    * 基本型テンプレートをチャンネル追加型テンプレートに、付加情報型テンプレートを複合型テンプレートに切り替えるAPIが追加されました。
    * チャンネル追加型に変更されるテンプレートは、ボタンの数が最大ボタン数より少なくなければなりません。
* [API]カカともへのメッセージボタンリンク型フィールドの長さ制限変更(500文字 → 2,000文字)
    * カカともへのメッセージボタンのPCリンクフィールド、モバイルリンクフィールドなどの最大長さ制限を2,000文字に変更しました。
* [API] 友だちトーク画像ファイルサイズ制限の変更（2MB → 5MB）
    * 友だちトークの画像ファイルの最大サイズ制限を5MBに変更しました。

### 2024. 02. 27. { #february-27-2024 }
* [コンソール]お知らせトークテンプレートの登録時にお問い合わせ及び添付ファイルの登録可能
    * テンプレート検収に必要な意見と添付ファイルをテンプレート作成過程で登録できるように改善しました。
    * 送金するボタンが追加されたテンプレート登録時に「決済会社を確認できる決済ページのキャプチャ画像」を一緒に添付して検収が可能です. [口座送金アプリリンクガイド](https://t1.daumcdn.net/kakaopay/static/guide/account-remittance-app-link/index.html)
* [コンソール]チャンネル追加型をデフォルトタイプに変更
    * (変更前)お知らせトークテンプレート登登録時、基本型タイプがデフォルトタイプ
    * (変更後)お知らせトークテンプレート登録時、チャンネル追加型がデフォルトタイプ
* [API]お知らせトークテンプレートのお問い合わせを行う時の添付ファイル数制限を変更
    * (変更前)お知らせトークテンプレートのお問い合わせ時に添付ファイルを5個まで登録可能
    * (変更後)お知らせトークテンプレートのお問い合わせ時に添付ファイルを10個まで登録可能
* [API]カカともへのメッセージワイドアイテムリストタイトル文字数制限を変更
    * (変更前) カカともへのメッセージワイドアイテムリストを送信する際、1～4番目のアイテムのタイトル文字数は25文字に制限
    * (変更後) カカともへのメッセージワイドアイテムリストを送信する際、最初のアイテムのタイトル文字数は25文字制限、2～4番目のアイテムのタイトル文字数は30文字制限
* [API]カカともへのメッセージカルーセルフィールド型カルーセル数制限を変更
    * (変更前)カカともへのメッセージカルーセルフィード型送信時、カルーセル数は2～6個まで.
    * (変更後)カカともへのメッセージカルーセルフィード型送信時のカルーセル数は2～10個まで.
* [API]カカともへのメッセージカルーセルフィード型ボタン数制限の変更
    * (変更前)カカともへのメッセージカルーセルフィード型送信時、カルーセルごとに5個までボタンを追加可能
    * (変更後)カカともへのメッセージカルーセルフィード型送信時、カルーセルごとに2つまでのボタンを追加可能
* [API]カカともへのメッセージボタンBC、BTタイプを削除
    * (変更前)カカともへのメッセージボタンの相談トーク切り替え、ボット切り替えタイプが使用可能
    * (変更後)カカともへのメッセージボタンの相談トーク切り替え、Bot切り替えタイプ使用不可
