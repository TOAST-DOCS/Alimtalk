### 2026. 08. 25. { #august-25-2026 }

#### 機能追加
* [API] ブランドメッセージ送信 API へのグループタグキーフィールド追加
    * ブランドメッセージの自由型および基本型送信 API に、カカオ統計で使用するグループタグキーフィールドが追加されました。
* [API] ブランドメッセージ一括送信照会 API 追加
    * ブランドメッセージの一括送信履歴を照会できる API が追加されました。

<a id="august-25-2026-feature-updates"></a>
#### 機能改善/変更
* [API] ブランドメッセージ コマース/カルーセルコマース 割引率の許容範囲変更
  * カカオの仕様変更に伴い、コマースおよびカルーセルコマースタイプの割引率（`discountRate`）の許容範囲が 0〜100 から 1〜100 に変更されました。

<a id="july-28-2026"></a>
### 2026. 07. 28. { #july-28-2026 }
<a id="feature-additions"></a>
#### 機能変更
* [API] ブランドメッセージ結果更新照会APIを追加
    * 結果更新日(`result_date`)を基準にブランドメッセージの送信結果を照会できるAPIが追加されました。
        * Endpoint: `GET /brand-message/v1.0/appkeys/{appKey}/message-results`
    * 照会可能期間は直近90日以内で、1回の照会範囲は最大31日です。

* [API] ブランドメッセージ080受信拒否認証番号の最大長さを変更
    * 080受信拒否認証番号の最大許容長が9文字から10文字に変更されました。

<a id="may-27-2026"></a>
### 2026. 05. 27. { #may-27-2026 }
* [API] Kakao Biz Centerの統計照会APIを追加
* Kakao Biz Centerで提供するお知らせトーク、ブランドメッセージの送信統計及びテンプレート統計を照会できるAPIが追加されました。
* 送信元キーを基準として日別(DAILY)または月別(MONTHLY)の統計データを照会できます。

* [API、コンソール] ブランドメッセージの画像削除に関するガイドを修正
* ブランドメッセージのテンプレート変更時に画像を変更すると、既存の画像がKakao CDNから削除され、同じ画像を使用する他のテンプレートにも影響するという内容にガイドが修正されました。

* [API、コンソール] ブランドメッセージのタイプ別内容の長さ制限を変更
* IMAGEタイプのメッセージの内容(content)の長さ制限が、最大400文字から最大1,300文字に変更されました。
* IMAGEタイプの改行制限が、最大29個から最大99個に変更されました。
* WIDE、PREMIUM_VIDEOタイプの改行制限が、最大1個から最大5個に変更されました。

<a id="february-24-2026"></a>
### 2026. 02. 24. { #february-24-2026 }
* [API] ブランドメッセージカルーセルの固定テンプレート変数を追加
    * カルーセルタイプのテンプレートで、各アイテムに異なるテンプレート変数の値を適用できます。
    * pathベースのパラメータ(`キー@$.carousel.list[インデックス]`)を使用してアイテム別のパーソナライズが可能です。
    * テンプレート変数のキーに'@'文字は使用できません。

* [API] ブランドメッセージテンプレート変数のキーのバリデーションを追加
    * テンプレートの登録/修正時に、テンプレート変数のキーに `@` 文字が含まれているとエラーが発生します。

* [API] ブランドメッセージ送信時のテンプレートパラメータ欠落チェックを追加
    * 送信リクエスト時に、テンプレートに定義されたテンプレート変数のキーがtemplateParameterに欠落しているとエラーが発生します。

* [API, コンソール] ブランドメッセージのBTボタンタイプをサポート
    * ブランドメッセージでBT(ボット切り替え)ボタンタイプをサポートします。
    * コンソールでBTボタンタイプを選択してテンプレートを登録できます。

* [API, コンソール] ブランドメッセージのACボタンタイプを追加
    * ブランドメッセージでAC(チャンネル追加)ボタンタイプをサポートします。
    * ACボタンの名前は必ず'チャンネル追加'でなければなりません。
    * カルーセルの場合、全アイテムの中でACボタンは1つだけ使用できます。

* [コンソール] お知らせトーク/ブランドメッセージ代替送信の応答メッセージ分類を改善
    * 代替送信時に応答メッセージが分類されて表示されます。

* [API] テンプレートパラメータの長さ制限を追加
    * テンプレートパラメータのキーと値は、それぞれ最大1,300文字に制限されます。

* [API] 受信者グルーピングキーの長さ制限を追加
    * recipientGroupingKeyフィールドの最大長が100文字に制限されます。
