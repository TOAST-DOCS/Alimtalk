#### 기능 추가
* [API] 브랜드 메시지 발송 API에 그룹 태그 키 필드 추가
    * 브랜드 메시지 자유형 및 기본형 발송 API에 카카오 통계에 사용하기 위한 그룹 태그 키 필드가 추가되었습니다.
* [API] 브랜드 메시지 대량 발송 조회 API 추가
    * 브랜드 메시지 대량 발송 내역을 조회할 수 있는 API가 추가되었습니다.

<a id="august-25-2026-feature-updates"></a>
#### 기능 개선/변경
* [API] 브랜드 메시지 커머스/캐러셀 커머스 할인율 허용 범위 변경
  * 카카오 스펙 변경에 따라 커머스 및 캐러셀 커머스 타입의 할인율(`discountRate`) 허용 범위가 0~100에서 1~100으로 변경되었습니다.

<a id="july-28-2026"></a>
### 2026. 07. 28. { #july-28-2026 }
<a id="feature-additions"></a>
#### 기능 변경
* [API] 브랜드 메시지 결과 업데이트 조회 API 추가
    * 결과 업데이트일(result_date) 기준으로 브랜드 메시지 발송 결과를 조회할 수 있는 API가 추가되었습니다.
        * Endpoint: `GET /brand-message/v1.0/appkeys/{appKey}/message-results`
    * 조회 가능 기간은 최근 90일 이내이며, 1회 조회 범위는 최대 31일입니다.

* [API] 브랜드 메시지 080 수신거부 인증 번호 최대 길이 변경
    * 080 수신거부 인증 번호의 최대 허용 길이가 9자에서 10자로 변경되었습니다.

### 2026. 06. 23. { #june-23-2026 }

<a id="june-23-2026-feature-additions"></a>
#### 기능 개선/변경
* [Console] 브랜드 메시지 비디오 업로드 기능 추가
    * 브랜드 메시지 프리미엄 비디오에 사용할 동영상을 콘솔에서 직접 업로드하고 관리할 수 있습니다.

    * 브랜드 메시지 프리미엄 비디오용 동영상을 업로드할 수 있는 API가 추가되었습니다.
* [API] 브랜드 메시지 결과 수신 웹훅에 채널 친구 여부 필드 추가
    * 브랜드 메시지 결과 수신 웹훅 응답에 수신자의 카카오 채널 친구 여부를 나타내는 `isAddedChannel`(Boolean) 필드가 추가되었습니다.

<a id="bug-fixes"></a>
#### 버그 수정
* [API] 브랜드 메시지·친구톡 광고 대체발송 시 080 수신거부 번호 처리 개선
    * 브랜드 메시지·친구톡 광고 대체발송 시 080 수신거부 번호가 없는 일부 케이스에서 일반 메시지로 발송되던 문제를 수정했습니다.

### 2026. 05. 27. { #may-27-2026 }
* [API] 카카오비즈센터 통계 조회 API 추가
    * 카카오비즈센터에서 제공하는 알림톡, 브랜드 메시지의 발송 통계 및 템플릿 통계를 조회할 수 있는 API가 추가되었습니다.
    * 발신 키 기준으로 일별(DAILY) 또는 월별(MONTHLY) 통계 데이터를 조회할 수 있습니다.

* [API, 콘솔] 브랜드 메시지 이미지 삭제 관련 가이드 수정
    * 브랜드 메시지 템플릿 수정 시 이미지를 변경하면 기존 이미지가 카카오 CDN에서 삭제되며, 동일한 이미지를 사용하는 다른 템플릿도 영향을 받는다는 내용으로 가이드가 수정되었습니다.

* [API, 콘솔] 브랜드 메시지 유형별 내용 길이 제한 변경
    * IMAGE 타입의 메시지 내용(content) 길이 제한이 최대 400자에서 최대 1,300자로 변경되었습니다.
    * IMAGE 타입의 줄바꿈 제한이 최대 29개에서 최대 99개로 변경되었습니다.
    * WIDE, PREMIUM_VIDEO 타입의 줄바꿈 제한이 최대 1개에서 최대 5개로 변경되었습니다.

### 2026. 02. 24. { #february-24-2026 }
* [API] 브랜드 메시지 캐러셀 고정 치환자 기능 추가
    * 캐러셀 타입 템플릿에서 각 아이템에 다른 치환자 값을 적용할 수 있습니다.
    * path 기반 파라미터(`키@$.carousel.list[인덱스]`)를 통해 아이템별 개인화가 가능합니다.
    * 템플릿 치환자 키에 '@' 문자를 사용할 수 없습니다.

* [API] 브랜드 메시지 템플릿 치환자 키 유효성 검사 추가
    * 템플릿 등록/수정 시 치환자 키에 `@` 문자가 포함되면 오류가 발생합니다.

* [API] 브랜드 메시지 발송 시 템플릿 파라미터 누락 검사 추가
    * 발송 요청 시 템플릿에 정의된 치환자 키가 templateParameter에 누락되면 오류가 발생합니다.

* [API, 콘솔] 브랜드 메시지 BT 버튼 타입 지원
    * 브랜드 메시지에서 BT(봇 전환) 버튼 타입을 지원합니다.
    * 콘솔에서 BT 버튼 타입을 선택하여 템플릿을 등록할 수 있습니다.

* [API, 콘솔] 브랜드 메시지 AC 버튼 타입 추가
    * 브랜드 메시지에서 AC(채널 추가) 버튼 타입을 지원합니다.
    * AC 버튼의 이름은 반드시 '채널 추가'여야 합니다.
    * 캐러셀의 경우 전체 아이템 중 AC 버튼은 1개만 사용 가능합니다.

* [콘솔] 알림톡/브랜드 메시지 대체 발송 응답 메시지 분류 개선
    * 대체 발송 시 응답 메시지가 분류되어 표시됩니다.

* [API] 템플릿 파라미터 길이 제한 추가
    * 템플릿 파라미터의 키와 값은 각각 최대 1,300자로 제한됩니다.

* [API] 수신자 그룹핑 키 길이 제한 추가
    * recipientGroupingKey 필드의 최대 길이가 100자로 제한됩니다.
