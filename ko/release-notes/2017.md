### 2017. 11. 23. { #november-23-2017 }
<a id="more-features-6"></a>
#### 기능 추가
* [콘솔] 다중 플러스친구 등록
    * 1개의 플러스친구 등록 구조에서 다중 플러스친구 구조로 변경되었습니다.
* [콘솔] 템플릿 반려 시, 템플릿 상세보기에서 반려 사유 제공.
* [API] 다중 플러스친구 적용에 따른 발송 API 필드 추가
    * requestBody에 plusFriendId 필드가 추가되었습니다.
    * plusFriendId 필드를 입력하지 않을 경우, 처음 등록된 플러스친구 ID로 발송됩니다.

### 2017. 08. 24. { #august-24-2017 }
<a id="more-features-7"></a>
#### 기능 추가
* [콘솔] 알림톡 발송 통계 화면 제공
    * 날짜별/시간대별/요일별 통계 화면이 제공됩니다.
    * 발송한 일자와 템플릿으로 조회할 수 있습니다.

<a id="feature-updates-4"></a>
#### 기능 개선/변경
* [콘솔] 자유버튼 템플릿 등록 시 URL 검증 변경
    * 자유버튼에 URL 등록 시, http:// or https:// 가 필수로 포함 → #{url}과 같이 템플릿 치환자도 등록할 수 있게 변경하였습니다.
    * 템플릿 치환자 #{url} 형식의 템플릿 치환자가 아닐 경우 http:// or https:// 검증은 유지됩니다.
* [API] Content-type 에러 응답 메시지 수정
    * 요청 header에 Content-type: application/json이 아닐 경우 실패 응답 메시지 수정되었습니다.
